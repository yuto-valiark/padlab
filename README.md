# PADLAB — Finger Drum Workstation

**▶ https://yuto-valiark.github.io/padlab/** （Chrome 推奨・インストール不要）

Mac のキーボードを 4×4 パッドにして、フィンガードラミングでビートを叩けるブラウザアプリ。

## 起動

```bash
npm install
npm run dev
```

ブラウザで表示された URL（通常 http://localhost:5173）を開き、何かキーを押すかクリックで電源 ON。
初めての時は 1 分のガイドツアーが始まり、最初のビートを作るところまで案内します。いつでも **`?`** キーで操作一覧（ツアーもそこから再開できます）。
**Chrome 推奨。入力は英数モードで。**

## 操作

| 操作 | キー |
|---|---|
| パッドを叩く | `1 2 3 4` / `Q W E R` / `A S D F` / `Z X C V`（Z が Pad 1） |
| 弱く叩く | `Shift` を押しながら |
| ノートリピート（連打） | `Option` を押しながらパッドを押しっぱなし |
| 連打の細かさ | `[` `]`（1/4 〜 1/32） |
| バンク A〜D | `←` `→` |
| タップテンポ | `T` |
| BPM ±1（Shift で ±0.1） | `-` `=` |
| 再生 / 停止 | `Space` |
| 録音（止まっていれば 1 小節カウントして開始） | `Enter` |
| メトロノーム ON/OFF | `M` |
| そのパッドのノートを全消去 | `Delete` を押しながらパッド |
| 元に戻す / やり直す | `⌘Z` / `⇧⌘Z` |

### シーケンサー
- マス目をクリックでノートを置く/消す。ドラッグで連続して塗れる。Shift+クリックで弱いノート。
- 行の名前をクリックで試聴。
- **TC（タイミング補正）**：録音したノートを 1/8〜1/32 のマスに寄せる。STRENGTH を下げると「人間っぽいズレ」を残せる。
- **SWING**：50%＝まっすぐ、60%前後でヒップホップっぽいヨレ、66%で 3 連っぽいシャッフル。
- **BARS**：ループの長さ（1/2/4 小節）。伸ばすと今のフレーズがコピーされる。
- **QUANTIZE**：今の TC 設定で、すでにあるノートを後からまとめて補正。
- 録音は 1 テイクまるごと 1 回の UNDO で戻せる。

マウスでもパッドを叩けます（パッドの上の方を叩くほど強い音）。ノブはドラッグで回す、ダブルクリックでリセット。

## 音素材

全 64 音をアプリ内でシンセサイズしています。外部サンプルは使っていません（[CREDITS.md](CREDITS.md)）。

## 開発

```bash
npm test        # ユニットテスト
npm run build   # 型チェック + 本番ビルド
```

### 練習モード（PRACTICE タブ）
- 左のレッスンを選んで **START**（または `Space`）。1 小節カウントのあと、右から流れてくる音符がオレンジの線に重なった瞬間に、左に書いてあるキーを叩く。
- 判定：PERFECT（±35ms）/ GREAT（±70ms）/ GOOD（±110ms）/ MISS。違うパッドや余計な連打は WRONG。
- 叩いた位置は白い線で残るので、早い・遅いが一目でわかる。下の EARLY/LATE メーターは直近 24 打のズレ。
- **♪ お手本**：正解の音を聴く（採点なし）。**GUIDE**：練習中もお手本を小さく鳴らす。
- **TEMPO**：60〜100% に落として練習できる。**LOOPS**：何周するか。
- 終わると S〜D のランクと、平均のズレ（例：+12ms＝少し遅め）とアドバイス、そのレッスンのスコア推移グラフ。
- **自分の演奏を聴く**：今の演奏をタイミングそのままで再生。
- 記録はブラウザ（localStorage）に保存される。

### サンプラー（PAD EDIT タブ）
- **自分の音を読み込む**：音声ファイル（WAV / MP3 / AIFF など）をパッドにドラッグ＆ドロップ、または LOAD。
- 波形の **S / E** をドラッグして再生範囲を決める。REV で逆再生。
- **ENVELOPE**：ATK / DEC / SUS / REL。GATE にすると押している間だけ鳴る。
- **FILTER**：LP / HP / BP と CUTOFF・RESO。**SENDS**：リバーブ・ディレイへの送り量。
- **CHOP**：AUTO（アタックを自動検出）か ÷4/÷8/÷16 で切って、配置先のバンク（A〜D）を押すと Pad 1 から順に並ぶ。波形クリックで切れ目追加、ドラッグで移動、⌥クリックで削除。
- RESET で元のシンセ音に戻る。

### ミキサー（MIXER タブ）
今のバンクの 16 パッドのフェーダー、PAN、REV/DLY センド、M（ミュート）/ S（ソロ）。ダブルクリックで初期値。

### エフェクト（FX タブ）
REVERB、DELAY（テンポ同期）、SIDECHAIN（LEARN を押してパッドを叩くとその音がトリガーに）、EQ、COMP、TAPE / LO-FI / VINYL。PRESET に CLEAN・LO-FI・TAPE WARM・PUMP。

### サンプリングと権利
自分で録った音・自作の音・CC0 などの権利フリー素材は自由に使えます。**他人の曲や市販音源をサンプリングした作品を公開・販売するには、権利者の許可（サンプル・クリアランス）が必要です。**

### 曲づくり（SONG タブ）
- **PATTERNS**：パターンは最大 16 個（P01〜P16）。NEW で空、DUP で今のパターンを複製。ダブルクリックで名前変更。クリックで編集対象を切り替え（SEQUENCER の左上 ‹ › でも可）。
- **ARRANGEMENT**：パターンの「＋」で曲の最後に追加。×回数・並べ替え・削除ができる。上の **PATTERN / SONG** で、今のパターンだけをループするか、曲を頭から通して再生するかを切り替え。
- 録音は PATTERN モードで（SONG モード中は録音しない）。

### 書き出し（SONG タブの EXPORT）
- 対象：SONG（曲全体）か、今のパターンを ×1 / ×4 / ×8。
- **2MIX .WAV**（24bit / 16bit）、**STEMS .ZIP**（パッドごとの WAV）、**.MID**（DAW 用。Pad 1 = C1 = 36、全 64 パッド = 36〜99）。
- エフェクト込みで、再生より速く書き出す。最後にリバーブの余韻 2.5 秒つき。

### 保存（左上のプロジェクト名）
- 作ったもの（パターン・曲・パッド設定・FX・読み込んだ音）はこのブラウザに**自動保存**。次に開くと前回のプロジェクトがそのまま戻る。
- プロジェクト名をクリックで一覧（NEW / SAVE AS / RENAME / 開く / 削除）。ダブルクリックで名前変更。
- ブラウザのデータを消すと消えるので、大事な曲は WAV / STEMS で書き出しておくこと。

### MIDI コントローラー
左上の **MIDI** → 接続する（Chrome / Edge）。強さもそのまま反映。
- **BANK**：C1〜D#2（36〜51）が今のバンクの Pad 1〜16。
- **ALL 64**：36〜99 が A01〜D16 の全パッド。
